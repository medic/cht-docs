## And more...

### Features

- [#10700](https://github.com/medic/cht-core/issues/10700): Support Photo Capture for Sub-contacts Within Parent Registration Forms
- [#9875](https://github.com/medic/cht-core/issues/9875): Support selecting from external dataset in forms

### Improvements

- [#10847](https://github.com/medic/cht-core/issues/10847): Allow searching contacts by local phone number format without country code prefix
- [#11174](https://github.com/medic/cht-core/issues/11174): Add document-returning `getPage` / `getAll` to `Contact.v1` and `Report.v1`
- [#11184](https://github.com/medic/cht-core/issues/11184): Update 3 filter UIs match each other: tasks, reports & targets
- [#8793](https://github.com/medic/cht-core/issues/8793): Block access for users with Chrome < 74 
- [#9725](https://github.com/medic/cht-core/issues/9725): "Unexpected Error" Dialog due to global database failure should not be optional

### Security fixes

None.

### Performance improvements

- [#10637](https://github.com/medic/cht-core/issues/10637): Remove or optimize map reduce view doc_summaries_by_id
- [#10638](https://github.com/medic/cht-core/issues/10638): Optimize map reduce view doc_by_type
- [#10651](https://github.com/medic/cht-core/issues/10651): Optimize indexes to reduce disk use (Hosting TCO)
- [#10748](https://github.com/medic/cht-core/issues/10748): Remove docs_by_id_lineage map reduce view
- [#10749](https://github.com/medic/cht-core/issues/10749): Move tasks_by_contact to offline clients only
- [#11125](https://github.com/medic/cht-core/issues/11125): Distribute nouveau across all couch nodes in multi-node deployments
- [#11215](https://github.com/medic/cht-core/issues/11215): Remove redundant map reduce view registered_patients
- [#6615](https://github.com/medic/cht-core/issues/6615): Consider moving outdated documents to "cold storage" (Hosting TCO)

### Bug fixes

- [#10851](https://github.com/medic/cht-core/issues/10851): Searching with Devanagari numerals no longer cross-matches Latin numeral contacts for online users (regression from 4.x)
- [#10963](https://github.com/medic/cht-core/issues/10963): Invalid config parsing in authorization.js leads to silent failures and unclear logging
- [#11218](https://github.com/medic/cht-core/issues/11218): Flaky e2e test:  users doc count        should return the configured limit and a log for every user:
- [#11241](https://github.com/medic/cht-core/issues/11241): Bikram Sambat (Nepali) date changes at 6:15 PM instead of local midnight
- [#11242](https://github.com/medic/cht-core/issues/11242): Mobile date tooltip clipped off the left edge of the viewport (report detail)
- [#11324](https://github.com/medic/cht-core/issues/11324): AndraBot: linked-issue check false-fails valid PRs on non-default branches (depends on GitHub's default-branch-only keyword linkage)
- [#11326](https://github.com/medic/cht-core/issues/11326): Deleted infodocs can cause an infinite loop in transitions
- [#7627](https://github.com/medic/cht-core/issues/7627): Memory leak caused by using the `countdown-widget` and the `geopicker` widget in the same form

### Technical improvements

- [#10875](https://github.com/medic/cht-core/issues/10875): Flaky api integration tests: transitions
- [#10953](https://github.com/medic/cht-core/issues/10953): Memory leak: unmanaged store subscription in FastActionButtonComponent constructor
- [#11194](https://github.com/medic/cht-core/issues/11194): Improve flaky test resolution process
