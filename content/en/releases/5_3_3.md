## Highlights

5.3.3 is a patch release that upgrades Node.js to address vulnerabilities from the [Node.js October 2026 security release](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases).

### Node.js 22.23.4

The `cht-api` and `cht-sentinel` images run Node.js 22.23.4, up from 22.23.2 ([#11515](https://github.com/medic/cht-core/issues/11515)). This version fixes the following vulnerabilities:

- **CVE-2026-111497** (High): An out-of-bounds write in the Brotli decoder that could allow remote code execution. API and Sentinel can reach this code through responses to outbound requests, for example [outbound push](/building/reference/app-settings/outbound/), [RapidPro](/building/integrations/rapidpro/), and Africa's Talking.
- **CVE-2026-106069** (High): A bypass of TLS hostname verification on outbound HTTPS requests.

The release also removes trust in the compromised eMudhra intermediate certificate authority (`emSign ECC Root CA - G3`) from both the Node.js certificate store and the `cht-nginx` image's `ca-certificates` bundle.
